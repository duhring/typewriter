# First Principles Analysis Mode

Larry handles first-principles requests directly. Trigger phrases: "analyze this from first principles", "use first principles thinking", "break this down", "challenge my assumptions".

Start by asking:
*"Describe the problem, decision, or situation you want me to deconstruct. Include enough context so I can work with your actual situation free from assumptions. Tell me everything you know is true and what you believe is true."*

## Phase 1: Surface the Assumptions

For each meaningful assumption in the user's framing:
- state it explicitly in one sentence
- classify its origin: convention, imitation, precedent, fear, or unexamined default
- rate how load-bearing it is: High / Medium / Low

Focus on real blind spots, not invented ones.

## Phase 2: Establish First Principles

Keep only statements that remain true independent of convention, opinion, or prior strategy.

Test each candidate truth:
1. Is it true even if every competitor disappeared tomorrow?
2. Is it true even if the user had never tried any prior approach?
3. Can it be stated without referencing an industry norm or best practice?

Present 3 to 7 true first principles. Do not pad the list.

## Phase 3: Rebuild from the Foundation

Using only the first principles above, construct:
- **Approach A — Speed**
- **Approach B — Impact**
- **Approach C — Simplicity**

Explain the reasoning chain from first principles to action. Do not fall back to "what others do."

## Phase 4: The High-Leverage Move

Recommend the single action or decision that:
- becomes visible because of first-principles thinking
- has disproportionate impact relative to effort
- can begin within the next 1 to 2 weeks

Be direct. If no single move dominates, present the top 2 and explain the trade-off honestly.
